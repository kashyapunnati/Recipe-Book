# 🍴 Recipe Book

A simple and interactive web-based Recipe Book application built using HTML5, CSS3, JavaScript, and LocalStorage.

## ✨ Features

- Add new recipes
- View complete recipe details
- Edit existing recipes
- Delete recipes
- Organize recipes by category
- Filter recipes by category
- Store recipes using LocalStorage
- Recipes remain saved after refreshing the page
- Responsive design for different screen sizes

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- LocalStorage

## 📋 CRUD Operations

This project implements complete CRUD functionality:

- **Create** → Add a new recipe
- **Read** → View recipe details
- **Update** → Edit an existing recipe
- **Delete** → Remove a recipe

## 🗂️ Categories

Recipes can be organized into:

- Breakfast
- Lunch
- Dinner
- Dessert
- Snacks

## 💾 LocalStorage

LocalStorage is used to save recipe data directly in the browser.

This allows recipes to remain available even after refreshing or reopening the webpage.

## 🚀 How to Use

1. Open `index.html` in a web browser.
2. Enter the recipe name.
3. Select a category.
4. Enter ingredients.
5. Enter cooking instructions.
6. Click **Add Recipe**.
7. Use **View**, **Edit**, or **Delete** for existing recipes.
8. Use the category filter to find recipes.
